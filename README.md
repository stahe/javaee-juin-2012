# Introduction à Java EE 5 / 6

👉 Cours en ligne :
[https://stahe.github.io/javaee-juin-2012/](https://stahe.github.io/javaee-juin-2012/)

## Présentation

Ce support de travaux dirigés (juin 2012) propose une introduction pratique à **Java EE** à travers la réalisation d’une application **trois couches** :

* Présentation
* Métier
* Accès aux données

Le document s’appuie sur Java EE 5 et 6 et utilise des **projets Maven**.

## Technologies abordées

### Application Web

* JSF (Java Server Faces)
* EJB3 ou Spring (couche métier)
* JPA (Hibernate / EclipseLink)

### Application Client / Serveur

* Swing (client graphique, support Spring)
* EJB3 ou Web Services (serveur)

## Objectifs pédagogiques

* Comprendre l’architecture d’une application d’entreprise Java
* Comparer EJB3 et Spring
* Mettre en œuvre JPA pour la persistance
* Construire une application complète avec NetBeans

Le document fournit les squelettes des solutions et laisse à l’étudiant le soin de compléter certaines parties.

## Pré-requis

* Connaissance du langage Java
* IDE NetBeans (environ 1 Go de RAM recommandé)
